# Evidências para o trabalho — Fase 1

Depois de publicar o projeto no GitHub, recomenda-se registrar no template da entrega:

1. **Repositório:** print da página principal mostrando a estrutura de pastas e arquivos.
2. **GitHub Actions:** print da aba Actions mostrando o workflow `CI - Build, Testes e Validação IaC` concluído com sucesso.
3. **Job Build e testes:** print das etapas `Executar build/validação sintática` e `Executar testes automatizados` com sucesso.
4. **Job Terraform:** print das etapas `terraform fmt -check`, `terraform init -backend=false` e `terraform validate` com sucesso.
5. **IaC:** print da pasta `terraform/` no repositório ou do conteúdo dos arquivos principais.

Também copie o link do repositório para as Seções 2 e 3 do template fornecido pelos professores.
